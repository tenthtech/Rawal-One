# Typeface

Rawal One uses a locally hosted Latin variable subset of **Public Sans**, by the Public Sans Project Authors, under the SIL Open Font License 1.1.

- Project: https://github.com/uswds/public-sans
- Distribution: `@fontsource-variable/public-sans` version 5.3.0
- Download: https://registry.npmjs.org/@fontsource-variable/public-sans/-/public-sans-5.3.0.tgz
- Bundled font: `public/fonts/public-sans-latin-variable.woff2` (unchanged from the distribution)
- Full copyright and licence: `public/fonts/OFL.txt`

No external font service is contacted by the application.
